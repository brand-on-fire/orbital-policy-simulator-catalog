# Notice

This repository publishes a single, force-reset snapshot of the full active-payload catalog for the Orbital Policy
Simulator on the `catalog-data` branch: one `catalog:active` columnar file (GP elements joined to SATCAT) and a tiny
manifest, replaced on each run with no retained history.

GP/SATCAT: USSPACECOM via Space-Track.org, distributed by CelesTrak (celestrak.org).

The snapshot is for visualization only. It is **not an archive** and is **NOT for conjunction assessment** or any
operational use. No satellite element is invented; every row derives from a real CelesTrak record.
